Use Herdr Canvas only after an explicit user request. The preferred trigger is
`canvas on`; also accept direct requests to use `herdr-canvas` or a live Herdr
canvas. Never open a canvas because a task is substantial, complex, involves
planning, investigation, implementation, or verification, or because the MCP
tools are available. Scope activation to the current task unless the user asks
to keep it on. Treat `canvas off`, `no canvas`, and `stop canvas updates` as
deactivation. If an explicit request cannot be fulfilled because the skill or
MCP is unavailable, explain once and continue the underlying task in chat.
