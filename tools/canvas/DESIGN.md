# Canvas visual direction

Reading this as: a terminal operations canvas for developers, in a restrained control-room visual language, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

- Color: terminal-native neutral text with cyan reserved for navigation and focus; semantic green, yellow, and red always include a glyph and label so state never depends on color alone.
- Layout: a fixed trusted header, flexible document viewport, optional trusted decision card, and compact keyboard footer keep ownership and interaction boundaries obvious.
- Typography: the terminal's configured typeface is retained because display-cell accuracy and user preference matter more than decorative font selection.
- Spacing: one-cell horizontal padding and framed trusted regions separate controls from document content without consuming the narrow 40 percent pane.
- Motion: live revisions update in place; no decorative animation competes with changing harness state.
- Identity motif: explicit operational labels such as CONNECTED, FOCUS, and ACTION REQUIRED make the canvas read as an instrument panel rather than a generic dashboard.
